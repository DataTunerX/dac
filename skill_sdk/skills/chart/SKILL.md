## 作用

这个 skill 只做一件事：让 ChartAgent（`http://biz-chart-agent.dac:10100`）根据用户提供的数据作图，并把对方给出的最终图表作为答案。

ChartAgent 能画的 ECharts 图包括饼图、柱状图、折线图、散点图、雷达图。用户如果要流程图、时序图、类图、状态图、ER 图、甘特图、思维导图，它会返回 Mermaid。它会先判断数据够不够画；不够就说明原因，不会补造数字。

服务器地址已经写在本 skill 的配置里。不要在工具参数里填写 URL，也不要改成别的地址。

## 做法

1. 从用户问题里整理出图表类型和原始数据。数字、类别、单位保持用户原文，不要改、不要补。
2. 调用一次 `a2a_chat`。`message` 里写清要什么图，并附上完整数据（表格或 JSON 均可）。这是一次新对话，不要依赖上一次调用。
3. 工具返回 JSON 的 `text` 才是结果。其中以 `[[DAC_PROGRESS]]` 开头的进度说明不是答案。
4. 用 `finish` 返回最终图表：
   - 成功时，`text` 里会有 ` ```chart ` 或 ` ```mermaid ` 代码块。把这个代码块原样作为最终答案，不要改写成别的格式，也不要另外编一份配置。
   - 对方明确说无法作图时，把这段说明原样返回。
5. 工具调用失败时，把错误告诉用户。不要在没有 `text` 的情况下自己画图。
