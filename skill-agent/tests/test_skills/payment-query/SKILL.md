# 支付查询能力

## 数据来源
支付数据存储在 `data/payments.txt` 文件中，实时同步，每行一条记录，字段以 `|` 分隔：
- 字段1：支付单号（如 PAY-001）
- 字段2：订单号（如 ORD-001）
- 字段3：用户ID（如 U001）——仅 ID，不是用户名
- 字段4：金额（元，可含小数）
- 字段5：支付方式（微信 / 支付宝 / 银行卡）
- 字段6：状态（成功 / 失败 / 待支付 / 退款中 / 已退款）
- 字段7：支付时间（YYYY-MM-DD HH:MM:SS）
- 字段8：退款金额（元；未退款为 0）

## 输入 / 输出
- 输入：支付单号、订单号、用户ID、支付状态、支付方式、时间范围
- 输出：支付单号、订单号、用户ID、金额、支付方式、状态、支付时间、退款金额
- 没有：用户名、电话、邮箱；商品ID、商品名称、标价；订单状态、发货状态；汇率、发票、对公账户

## 数据查询方式
- 读取全部支付：`cat data/payments.txt`
- 按支付单号查询：`grep "PAY-001" data/payments.txt`
- 按订单号查询：`grep "ORD-001" data/payments.txt`
- 按用户ID查询：`grep "U001" data/payments.txt`
- 按状态筛选：`grep "已退款" data/payments.txt`
- 汇总退款金额：`awk -F'|' '$6=="已退款" {sum+=$8} END {print sum}' data/payments.txt`
- 按支付方式汇总：`awk -F'|' '{amt[$5]+=$4} END {for (m in amt) print m, amt[m]}' data/payments.txt`
- 允许工具：cat、grep、awk、sort、uniq、wc（只读）

## 支持的查询场景
1. 按支付单号查支付详情
2. 按订单号查对应支付/退款记录
3. 按用户ID列出支付流水
4. 按状态或支付方式筛选、统计
5. 汇总成功支付额或退款总额

## 跨域规划（强制）
- 没有用户ID时不要猜测用户名对应谁；用户名解析属于 **user_query**。
- 没有订单号时不要编造；订单状态/商品ID 属于 **order_query**，本技能只有订单号这一外键。
- 只读。不能发起支付、申请退款、取消支付或改状态。
