# 营销活动查询能力

## 数据来源
1. 活动台账 `data/campaigns.txt`，每行一条，字段以 `|` 分隔：
   - 字段1：活动ID（如 CMP-001）
   - 字段2：活动名称
   - 字段3：投放渠道（微信 / 支付宝 / 站内 / 信息流）
   - 字段4：状态（未开始 / 进行中 / 已暂停 / 已结束）
   - 字段5：开始日期（YYYY-MM-DD）
   - 字段6：结束日期（YYYY-MM-DD）
   - 字段7：预算（元）
   - 字段8：已消耗（元）
   - 字段9：优惠券批次号（如 CPN-A09）
   - 字段10：目标品类（电子 / 食品 / 家居 / 美妆 / 全场）
2. 优惠券批次 `data/coupons.txt`，每行一条，字段以 `|` 分隔：
   - 字段1：券批次号
   - 字段2：规则文案（如 满1000减100）
   - 字段3：适用品类
   - 字段4：生效日期
   - 字段5：失效日期
   - 字段6：发放量
   - 字段7：核销量

活动与券批次每日凌晨同步（非实时成交）。

## 输入 / 输出
- 输入：活动ID、活动名称关键词、渠道、状态、券批次号、日期范围、目标品类
- 输出：活动台账字段；券规则、发放量、核销量；预算与消耗（可算消耗率）
- 没有：订单号、GMV、支付金额、转化率漏斗用户明细；商品ID/名称/标价/库存；用户姓名与用户ID；广告创意/文案素材

## 数据查询方式
- 读取全部活动：`cat data/campaigns.txt`
- 按活动ID：`grep "CMP-001" data/campaigns.txt`
- 按渠道：`grep "微信" data/campaigns.txt`
- 进行中活动：`grep "进行中" data/campaigns.txt`
- 按券批次：`grep "CPN-A09" data/coupons.txt`
- 汇总预算与消耗：`awk -F'|' '{b+=$7; s+=$8} END {print b, s}' data/campaigns.txt`
- 允许工具：cat、grep、awk、sort、uniq、wc（只读）

## 支持的查询场景
1. 按活动ID查预算、消耗、状态、起止日期
2. 按渠道或状态列出活动
3. 查询某券批次规则、发放量与核销量
4. 按品类筛选营销活动
5. 汇总预算、消耗，计算消耗率

## 跨域规划（强制）
- 「活动卖了多少 / GMV / 谁下了单」不是本域，交给 **order_query** / **payment_query**。
- 目标品类不是商品目录；要名称和标价交给 **product_query**。
- 只读。不能创建活动、暂停投放、追加预算、发放优惠券或生成广告文案。
