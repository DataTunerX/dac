# 库存查询能力

## 数据来源
库存数据存储在 `data/inventory.txt` 文件中，每 15 分钟同步一次（非实时），每行一条记录，字段以 `|` 分隔：
- 字段1：仓库ID（如 WH-001）
- 字段2：仓库名称（华东仓 / 华北仓 / 华南仓）
- 字段3：商品ID（如 PROD-001）——仅 ID，不是商品名称
- 字段4：当前库存量（整数）
- 字段5：安全库存阈值（整数）
- 字段6：最近入库时间（YYYY-MM-DD HH:MM:SS）
- 字段7：最近出库时间（YYYY-MM-DD HH:MM:SS）

## 输入 / 输出
- 输入：仓库ID、商品ID，或「低于安全阈值」这类库存条件
- 输出：仓库ID、仓库名称、商品ID、当前库存量、安全库存阈值、最近入出库时间
- 没有：商品名称、标价、分类、规格；订单号、销量；用户姓名/用户ID；支付与退款；物流轨迹

## 数据查询方式
- 读取全部库存：`cat data/inventory.txt`
- 按商品ID查询：`grep "PROD-001" data/inventory.txt`
- 按仓库ID查询：`grep "WH-001" data/inventory.txt`
- 低于安全阈值：`awk -F'|' '$4<$5' data/inventory.txt`
- 按仓库汇总库存量：`awk -F'|' '{sum[$1]+=$4} END {for (w in sum) print w, sum[w]}' data/inventory.txt`
- 允许工具：cat、grep、awk、sort、uniq、wc（只读）

## 支持的查询场景
1. 查询某商品在各仓库的库存量
2. 查询某仓库内全部商品库存
3. 列出库存低于安全阈值的记录
4. 按仓库汇总库存总量
5. 查看某商品最近入出库时间

## 跨域规划（强制）
- 必须先有商品ID或仓库ID。用户名、订单号、商品名称都不是本技能的过滤键。
- 用户要商品名称或官方标价时，本技能只返回商品ID与库存数字；名称/标价属于 **product_query**。
- 在途采购数量属于 **procurement_query**；运单派送轨迹属于 **logistics_query**。
- 只读。不能调拨、盘点写入、修改阈值或创建入库单。
