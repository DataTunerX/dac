# 客服工单查询能力

## 数据来源
工单数据存储在 `data/tickets.txt` 文件中，每行一条记录，字段以 `|` 分隔：
- 字段1：工单号（如 TKT-001）
- 字段2：用户ID（如 U001）——仅 ID，不是用户名
- 字段3：工单类型（售后 / 物流咨询 / 发票 / 账户 / 投诉）
- 字段4：优先级（低 / 中 / 高 / 紧急）
- 字段5：状态（待处理 / 处理中 / 待用户回复 / 已解决 / 已关闭）
- 字段6：创建时间（YYYY-MM-DD HH:MM:SS）
- 字段7：处理人
- 字段8：摘要（一句话问题描述，不是聊天记录全文）

工单队列近实时同步（约 5 分钟延迟）。

## 输入 / 输出
- 输入：工单号、用户ID、工单类型、状态、处理人、时间范围
- 输出：工单号、用户ID、类型、优先级、状态、创建时间、处理人、摘要
- 没有：用户名、电话、邮箱；订单金额、商品名称、库存；物流单号与轨迹；知识库文章/FAQ 全文；质检评分

## 数据查询方式
- 读取全部工单：`cat data/tickets.txt`
- 按工单号查询：`grep "TKT-001" data/tickets.txt`
- 按用户ID查询：`grep "U001" data/tickets.txt`
- 按类型筛选：`grep "售后" data/tickets.txt`
- 按状态筛选：`grep "处理中" data/tickets.txt`
- 按处理人筛选：`grep "客服-小陈" data/tickets.txt`
- 统计各状态数量：`awk -F'|' '{c[$5]++} END {for (s in c) print s, c[s]}' data/tickets.txt`
- 允许工具：cat、grep、awk、sort、uniq、wc（只读）

## 支持的查询场景
1. 按工单号查工单详情
2. 按用户ID列出该用户工单
3. 按类型、状态、优先级筛选
4. 按处理人查看待办
5. 统计工单量（按状态/类型）

## 跨域规划（强制）
- 没有用户ID时不要用用户名查工单；用户名解析属于 **user_query**。
- 工单摘要里出现订单号时，物流轨迹交给 **logistics_query**；仓库库存交给 **inventory_query**。
- 只读。不能创建工单、改派、升级、关闭或回复用户。
