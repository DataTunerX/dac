# 物流轨迹查询能力

## 数据来源
运单数据存储在 `data/shipments.txt` 文件中，约 10 分钟同步一次，每行一条记录，字段以 `|` 分隔：
- 字段1：运单号（如 SHP-001）
- 字段2：订单号（如 ORD-001）——仅订单号，不是订单状态或金额
- 字段3：承运商（顺丰 / 京东 / 圆通 / 中通）
- 字段4：物流状态（待揽收 / 已揽收 / 运输中 / 派送中 / 已签收 / 异常）
- 字段5：当前站点
- 字段6：轨迹更新时间（YYYY-MM-DD HH:MM:SS）
- 字段7：签收时间（未签收则为空）

## 输入 / 输出
- 输入：运单号、订单号、承运商、物流状态、时间范围
- 输出：运单号、订单号、承运商、物流状态、当前站点、更新时间、签收时间
- 没有：用户名、用户ID、电话；商品ID、名称、标价、仓库库存；支付金额；客服工单；采购在途

## 数据查询方式
- 读取全部运单：`cat data/shipments.txt`
- 按运单号查询：`grep "SHP-001" data/shipments.txt`
- 按订单号查询：`grep "ORD-001" data/shipments.txt`
- 按承运商筛选：`grep "顺丰" data/shipments.txt`
- 按状态筛选：`grep "运输中" data/shipments.txt`
- 未签收：`awk -F'|' '$7==""' data/shipments.txt`
- 允许工具：cat、grep、awk、sort、uniq、wc（只读）

## 支持的查询场景
1. 按运单号查当前站点和状态
2. 按订单号反查运单
3. 按承运商或状态筛选
4. 列出未签收 / 异常件
5. 统计各承运商运单量

## 跨域规划（强制）
- 没有订单号或运单号时不要用用户名查物流。
- 仓库现存量属于 **inventory_query**；采购未到货属于 **procurement_query**；工单摘要属于 **ticket_query**。
- 只读。不能修改收货地址、拦截包裹或标记签收。
