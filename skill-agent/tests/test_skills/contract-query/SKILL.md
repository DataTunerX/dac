# 合同台账查询能力

## 数据来源
合同台账存储在 `data/contracts.txt` 文件中，每行一条记录，字段以 `|` 分隔：
- 字段1：合同号（如 CON-001）
- 字段2：对方名称
- 字段3：合同类型（采购 / 销售 / 租赁 / 服务）
- 字段4：合同金额（元）
- 字段5：签署日（YYYY-MM-DD）
- 字段6：生效日（YYYY-MM-DD）
- 字段7：到期日（YYYY-MM-DD）
- 字段8：状态（草稿 / 履行中 / 已到期 / 已终止）
- 字段9：负责人工号（如 EMP-001）——仅工号，不是姓名

台账每周同步一次，不含合同 PDF 正文。

## 输入 / 输出
- 输入：合同号、对方名称、合同类型、状态、负责人工号、到期日范围
- 输出：合同号、对方、类型、金额、签署/生效/到期日、状态、负责人工号
- 没有：合同条款原文、风险点、用印记录；劳动法/经济补偿/加班费；员工姓名；报销单；采购行（物料、数量、进货价）；营销预算

## 数据查询方式
- 读取全部合同：`cat data/contracts.txt`
- 按合同号：`grep "CON-001" data/contracts.txt`
- 按对方名称：`grep "华储电子" data/contracts.txt`
- 按类型：`grep "采购" data/contracts.txt`
- 按负责人工号：`grep "EMP-001" data/contracts.txt`
- 即将到期（例如 2026-10-01 前）：`awk -F'|' '$7<="2026-10-01"' data/contracts.txt`
- 允许工具：cat、grep、awk、sort、uniq、wc（只读）

## 支持的查询场景
1. 按合同号查金额、期限、状态
2. 按对方或类型列出合同
3. 按负责人工号查名下合同
4. 筛选履行中或即将到期的合同
5. 按类型汇总合同金额

## 跨域规划（强制）
- 采购行项目（物料、数量、交期）属于 **procurement_query**；报销明细属于 **expense_query**。
- 不解读劳动法，也不做合同全文风险审查。
- 只读。不能起草合同、提交审批、用印或终止合同。
