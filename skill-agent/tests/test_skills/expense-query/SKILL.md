# 报销单查询能力

## 数据来源
报销单数据存储在 `data/expenses.txt` 文件中，每行一条记录，字段以 `|` 分隔：
- 字段1：报销单号（如 EXP-001）
- 字段2：员工工号（如 EMP-001）——仅工号，不是姓名，也不是电商用户ID
- 字段3：费用类型（差旅交通 / 住宿 / 餐饮 / 招待费 / 办公用品）
- 字段4：金额（元）
- 字段5：发生日期（YYYY-MM-DD）
- 字段6：审批状态（草稿 / 审批中 / 已通过 / 已驳回 / 已打款）
- 字段7：发票号

每日凌晨同步财务系统快照（非实时）。

## 输入 / 输出
- 输入：报销单号、员工工号、费用类型、审批状态、日期范围
- 输出：报销单号、员工工号、费用类型、金额、发生日期、审批状态、发票号
- 没有：员工姓名、部门、职级；电商用户ID、订单、商品；工资、奖金、社保、个税；差旅标准/报销制度原文（制度问答请用 **hr_policy_qa**）

## 数据查询方式
- 读取全部报销单：`cat data/expenses.txt`
- 按报销单号查询：`grep "EXP-001" data/expenses.txt`
- 按员工工号查询：`grep "EMP-001" data/expenses.txt`
- 按费用类型筛选：`grep "差旅交通" data/expenses.txt`
- 按审批状态筛选：`grep "已通过" data/expenses.txt`
- 汇总某员工金额：`awk -F'|' '$2=="EMP-001" {sum+=$4} END {print sum}' data/expenses.txt`
- 允许工具：cat、grep、awk、sort、uniq、wc（只读）

## 支持的查询场景
1. 按报销单号查详情
2. 按员工工号列出报销单
3. 按费用类型或审批状态筛选
4. 按日期范围筛选
5. 汇总金额、统计单量

## 跨域规划（强制）
- 不能按姓名查。姓名→工号 不属于本技能；本技能也不认电商用户ID（U001）。
- 问「差旅标准、需要哪些发票、审批流程」是制度问题，交给 **hr_policy_qa**，不要把制度写进报销单返回值。
- 只读。不能创建报销单、提交审批、通过/驳回或标记打款。
