# HR 制度问答能力

## 覆盖范围
- 文档集：`data/` 目录下的公司内部制度原文
  - `data/leave.txt`：请假与年假
  - `data/attendance.txt`：考勤打卡与迟到旷工
  - `data/reimbursement.txt`：报销材料与差旅标准
  - `data/onboarding.txt`：入职离职手续
  - `data/welfare.txt`：福利与补贴
- 主题：考勤、请假、年假、病假事假、报销、差旅、福利、入职、离职流程
- 版本：2024–2025，每季度更新
- 语言：中文
- 模态：纯文本；不支持 PDF、图片、扫描件

## 输入 / 输出
- 输入：中文自然语言问题（文本）
- 输出：制度要点摘要 + 出处（文件名与章节标题）
- 没有：某位员工的假期余额、打卡记录、报销单金额；工资表、期权协议；劳动法条原文与经济补偿法定计算公式

## 处理流程
1. 根据问题关键词在 `data/` 中检索相关章节：`grep -n "年假" data/*.txt`
2. 阅读命中段落，归纳成简短回答
3. 回答末尾必须给出出处，例如：`出处：data/leave.txt「年假」`
4. 允许工具：cat、grep、awk、sed、head、wc（只读）

## 支持的查询场景
1. 年假天数与申请时限
2. 迟到、旷工如何计
3. 差旅报销需要哪些材料、住宿标准
4. 入职/离职办理步骤
5. 餐补、通讯补等福利口径

## 注意事项（强制）
- 正文没写的制度视为没有，不要用通用 HR 常识补全。
- **不覆盖**薪酬体系、调薪方案、股票期权、绩效评定与晋升。
- **不覆盖**国家法律层面的解除劳动合同、加班费法定倍率、经济补偿金计算。
- 只读。不能帮用户提交请假、改考勤或审批报销。
